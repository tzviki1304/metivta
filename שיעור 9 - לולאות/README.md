## 🎯 מה נלמד היום?

✅ **לולאת for** — כשיודעים כמה פעמים  
✅ **לולאת while** — כשלא יודעים כמה פעמים  
✅ **for...of** — לולאה על מערך (הכי נוחה!)  
✅ **break** — עצור את הלולאה  
✅ **continue** — דלג לאיטרציה הבאה  
✅ **לולאות מקוננות** — לולאה בתוך לולאה  

---

## 🔑 מושגי מפתח

### לולאת for
```javascript
// for (התחלה; תנאי-המשך; צעד)
for (let i = 0; i < 5; i++) {
    console.log(i)  // 0, 1, 2, 3, 4
}
```

### for...of — הכי קל על מערכים!
```javascript
let names = ["דן", "שרה", "משה"]
for (let name of names) {
    console.log(name)  // דן, שרה, משה
}
```

### לולאת while
```javascript
let count = 0
while (count < 5) {
    console.log(count)
    count++        // חשוב! בלי זה לולאה אינסופית
}
```

### break ו-continue
```javascript
for (let i = 0; i < 10; i++) {
    if (i === 5) break      // עוצר לגמרי
    if (i % 2 === 0) continue  // מדלג על זוגיים
    console.log(i)  // 1, 3
}
```

### לולאות מקוננות — לוח כפל
```javascript
for (let i = 1; i <= 3; i++) {
    for (let j = 1; j <= 3; j++) {
        console.log(`${i} × ${j} = ${i * j}`)
    }
}
```

## ⚠️ שגיאות נפוצות

| שגיאה | תיקון |
|-------|-------|
| שכחתי `i++` — לולאה אינסופית! | תמיד ודא שהתנאי מתקדם לקראת סיום |
| `i < arr.length` vs `i <= arr.length` | לרוב `<` כי index מתחיל מ-0 |
| שינוי המערך בתוך הלולאה | היזהר — זה יכול לגרום לבאגים |

---

## 💡 מתי להשתמש?

| מצב | לולאה |
|-----|-------|
| יודע בדיוק כמה פעמים | `for` |
| עובר על מערך | `for...of` או `forEach` |
| תלוי בקלט משתמש | `while` |
| עובר על אינדקסים | `for` עם `i` |
