🔢 משימת בית — מספרים ראשוניים

מה זה מספר ראשוני?

מספר שמתחלק רק ב-1 ובעצמו!

✅ ראשוניים: 2, 3, 5, 7, 11, 13...

❌ לא ראשוניים: 4 (÷2), 6 (÷2,3), 9 (÷3)

⭐ המשימה:

  1. קבל מספר N מהמשתמש
  2. מצא וה‍צג את כל המספרים הראשוניים עד N
  3. ה‍צג בסגול את הראשוניים ובאפור את שאר המספרים
  4. בונוס: ה‍צג כמה ראשוניים מצאת
  5. בונוס 2: כתוב פונקציה isPrime(n) שמחזירה true/false
💡 כיצד לבדוק אם מספר ראשוני?
בדוק אם הוא מתחלק ב-אחד ממספרים 2, 3, 4, ..., n-1
אם שום מספר לא מחלק אותו — הוא ראשוני!

function isPrime(n) {
  if (n < 2) return false
  for (let i = 2; i < n; i++) {
    if (n % i === 0) return false  // מצאנו מחלק!
  }
  return true  // לא מצאנו מחלק → ראשוני
}
