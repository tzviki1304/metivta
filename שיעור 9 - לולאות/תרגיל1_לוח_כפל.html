✖️ תרגיל — לוח כפל

📋 המשימה:

  1. קבל מספר N מהמשתמש
  2. בנה טבלת כפל N×N (לולאות מקוננות!)
  3. בונוס: הדגש בצבע שונה את האלכסון (שם i === j)
  4. בונוס 2: הוסף כותרת-עמודה וכותרת-שורה
💡 רמז — לולאות מקוננות: 
for (let i = 1; i <= n; i++) {        // שורה
    for (let j = 1; j <= n; j++) {    // עמודה
        // i * j = התוצאה
    }
}
כדי לבנות טבלה: 
let table = document.createElement("table")
let row = document.createElement("tr")
let cell = document.createElement("td")
cell.textContent = i * j
row.appendChild(cell)
table.appendChild(row)
