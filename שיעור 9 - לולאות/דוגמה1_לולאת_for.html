🔄 לולאת for

מבנה לולאת for

for (let i = 0; i < 5; i++) { // ↑ ↑ ↑ // התחלה תנאי צעד console.log(i) }

שלושת החלקים:

1. let i = 0 — ערך התחלתי 2. i < 5 — כל עוד זה נכון, המשך 3. i++ — הוסף 1 אחרי כל סיבוב
לחץ הרץ...

לולאה על מערך עם index

let fruits = ["🍎 תפוח", "🍌 בננה", "🍊 תפוז"] for (let i = 0; i < fruits.length; i++) { console.log(`[${i}] ${fruits[i]}`) }

for...of — הדרך הנוחה על מערך!

let names = ["דן", "שרה", "משה", "רחל"] for (let name of names) { console.log(`שלום, ${name}!`) }

לולאות מקוננות (לולאה בתוך לולאה)

for (let i = 1; i <= 3; i++) { for (let j = 1; j <= 3; j++) { console.log(`${i} × ${j} = ${i * j}`) } }
