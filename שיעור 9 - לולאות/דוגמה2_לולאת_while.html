🔁 לולאת while

מתי to use while?

כשלא יודעים מראש כמה פעמים הלולאה תרוץ — תלוי בתנאי.

// while — "כל עוד" let count = 0 while (count < 5) { // כל עוד count קטן מ-5 console.log(count) count++ // ⚠️ חשוב מאוד! } // בלי count++ — לולאה אינסופית!

הכפלה עד גבול — דוגמה מציאותית

// הכפל ב-2 עד שמגיעים ל-1000 let num = 1 while (num < 1000) { num = num * 2 console.log(num) }

do...while — רץ לפחות פעם אחת

let answer do { answer = prompt("מה 5 כפול 5?") } while (answer !== "25") console.log("נכון!")
