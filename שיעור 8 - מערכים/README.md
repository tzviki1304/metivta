## 🎯 מה נלמד היום?

✅ **יצירת מערך** — `let arr = [1, 2, 3]`  
✅ **גישה לאיברים** — `arr[0]`, `arr.length`  
✅ **הוספה ומחיקה** — `push()`, `pop()`, `shift()`, `unshift()`  
✅ **חיפוש** — `indexOf()`, `includes()`  
✅ **שינוי מערך** — `map()`, `filter()`  
✅ **מיון** — `sort()`, `reverse()`

## 🔑 מושגי מפתח

### יצירת מערך
```javascript
let fruits = ["תפוח", "בננה", "תפוז"]
let numbers = [10, 20, 30, 40, 50]
let mixed = ["שלום", 42, true]
```

### גישה לאיברים (מתחיל מ-0!)
```javascript
let fruits = ["תפוח", "בננה", "תפוז"]
console.log(fruits[0])   // "תפוח"
console.log(fruits[1])   // "בננה"
console.log(fruits.length)  // 3
```

### push ו-pop
```javascript
let list = ["א", "ב"]
list.push("ג")    // מוסיף לסוף → ["א", "ב", "ג"]
list.pop()        // מסיר מהסוף → ["א", "ב"]
```

### map — שינוי כל האיברים
```javascript
let prices = [10, 20, 30]
let doubled = prices.map(p => p * 2)
// [20, 40, 60]
```

### filter — סינון לפי תנאי
```javascript
let numbers = [1, 2, 3, 4, 5, 6]
let evens = numbers.filter(n => n % 2 === 0)
// [2, 4, 6]
```

## 💡 טיפ חשוב
> מערך מתחיל ב-index **0**, לא 1!
> אם יש 3 איברים, ה-index הוא 0, 1, 2.
> `arr[arr.length - 1]` הוא תמיד האיבר **האחרון**.
