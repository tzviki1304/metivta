📊 תרגיל — ניתוח ציונים

📋 המשימה:

  1. קבל ציונים מהמשתמש (בין 0 ל-100)
  2. הצג את כל הציונים (ירוק אם ≥70, אדום אם <70)
  3. חשב וה‍צג: ממוצע, הציון הגבוה ביותר, הנמוך ביותר
  4. ה‍צג כמה ציונים עוברים (≥60)
  5. בונוס: הצג את הציונים ממוינים מהגבוה לנמוך
💡 רמזים:
• ממוצע: grades.reduce((sum, g) => sum + g, 0) / grades.length
• מקסימום: Math.max(...grades)
• מינימום: Math.min(...grades)
• מיון יורד: grades.sort((a, b) => b - a)
