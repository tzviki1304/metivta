📋 מערך בסיסי

מה זה מערך?

מערך הוא קופסה שמכילה כמה ערכים בתוכה, בסדר מסוים.

let fruits = ["תפוח", "בננה", "תפוז", "ענבים"] // index: 0 1 2 3

🎬 ניסוי — לחץ על הכפתורים!

לחץ על כפתור...

💡 כלל חשוב: index מתחיל מ-0!

let fruits = ["תפוח", "בננה", "תפוז"] fruits[0] // "תפוח" ← ראשון fruits[1] // "בננה" ← שני fruits[2] // "תפוז" ← שלישי fruits.length // 3 (כמות האיברים) fruits[fruits.length - 1] // "תפוז" ← אחרון תמיד!
