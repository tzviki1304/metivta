## 🎯 מה נלמד היום?

✅ **יצירת אובייקט** — `{ key: value }`  
✅ **גישה לנכסים** — `obj.key` ו-`obj["key"]`  
✅ **שינוי נכסים** — `obj.key = newValue`  
✅ **מתודות** — פונקציות בתוך אובייקט  
✅ **Object.keys(), Object.values()**  
✅ **מערך של אובייקטים** + filter/map  
✅ **Destructuring** — פירוק אובייקט

## 🔑 מושגי מפתח

### יצירת אובייקט
```javascript
let person = {
    name: "ישראל",
    age: 25,
    city: "תל אביב"
}
```

### גישה לנכסים
```javascript
console.log(person.name)       // "ישראל"
console.log(person["age"])     // 25
person.email = "israel@email.com"  // הוספת נכס
```

### מתודות — פונקציות בתוך אובייקט
```javascript
let car = {
    brand: "טויוטה",
    speed: 0,
    accelerate() {
        this.speed += 10
        return `מהירות: ${this.speed}`
    }
}
car.accelerate()  // "מהירות: 10"
```

### מערך של אובייקטים
```javascript
let students = [
    { name: "דן", grade: 85 },
    { name: "שרה", grade: 92 },
    { name: "משה", grade: 67 }
]

// filter — רק עוברים
let passing = students.filter(s => s.grade >= 70)

// map — רק השמות
let names = students.map(s => s.name)
```

### Destructuring — פירוק קצר
```javascript
let { name, age } = person
// שווה ל:
let name = person.name
let age = person.age
```

## 💡 אובייקט vs מערך

| מצב | מה להשתמש? |
|-----|------------|
| רשימה מסודרת של דברים | מערך `[]` |
| תיאור של ישות אחת | אובייקט `{}` |
| רשימה של ישויות | מערך של אובייקטים `[{}, {}]` |
