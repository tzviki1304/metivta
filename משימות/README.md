## 🛠️ איך להתחיל?

**שלב 1:** הורד **VS Code** (חינם) מ: https://code.visualstudio.com

**שלב 2:** הוסף את התוסף **"Live Server"** ב-VS Code (לחץ על אייקון ריבועים בצד)

**שלב 3:** פתח קובץ HTML חדש — תלחץ F5 וזה יפתח בדפדפן אוטומטי!

**שלב 4:** קרא את המשימה כמו מתכון — ה**שלבים הם הדרכה**, לא קוד מוכן.
