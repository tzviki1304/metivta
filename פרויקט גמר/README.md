## 💡 רעיון 1: אפליקציית ניהול משימות חכמה (Task Manager)

**קישור לתיקייה:** [רעיון1_אפליקציית_משימות/](רעיון1_אפליקציית_משימות/README.md)

### מה תבנה:
אפליקציה שנראית ומרגישה כמו Trello / Todoist — עם עיצוב מקצועי.

### תכונות בסיסיות:
- ✅ הוסף / מחק / סמן משימות כהושלם
- 🏷️ קטגוריות (עבודה / לימודים / אישי)
- ⭐ עדיפות (גבוה / בינוני / נמוך)
- 💾 שמירה ב-LocalStorage (נשמר בין רענונים)

### תכונות בונוס:
- 📅 תאריך יעד + התראה אם עבר
- 🔍 חיפוש משימות
- 📊 גרף סיכום (כמה הושלמו)
- 🌙 Dark Mode

## 💡 רעיון 2: אתר פורטפוליו אישי (Personal Portfolio)

**קישור לתיקייה:** [רעיון2_אתר_פורטפוליו/](רעיון2_אתר_פורטפוליו/README.md)

### מה תבנה:
אתר שמציג **אותך** — שאפשר לשלוח למעסיקים!

### תכונות בסיסיות:
- 🙋 עמוד "אודות" — מי אתה, מה אתה לומד
- 💼 גלריית פרויקטים — עם כל מה שבנינו בקורס
- 📬 טופס יצירת קשר
- 📱 Responsive (עובד בפלאפון!)

### תכונות בונוס:
- ✨ אנימציות CSS
- 🌙 Dark / Light Mode
- 🖨️ כפתור "הורד CV"
- 📊 "Skills Bar" — סרגל מיומנויות
