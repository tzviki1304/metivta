💾 LocalStorage — זיכרון הדפדפן

מה זה LocalStorage?

כמו מחברת קטנה בדפדפן — שומר נתונים גם אחרי סגירת הטאב!

// שמור localStorage.setItem("key", "value") // קרא let val = localStorage.getItem("key") // "value" // מחק localStorage.removeItem("key") // נקה הכל localStorage.clear()

ניסוי — שמור שם

לחץ "טען" לראות אם יש שם שמור...

שמירת אובייקטים — JSON

// אובייקטים צריכים המרה ל-JSON! let user = { name: "ישראל", score: 42 } // שמור ← JSON.stringify localStorage.setItem("user", JSON.stringify(user)) // קרא ← JSON.parse let loaded = JSON.parse(localStorage.getItem("user")) console.log(loaded.name) // "ישראל"
