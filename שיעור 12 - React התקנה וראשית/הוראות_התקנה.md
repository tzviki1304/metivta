# הוראות התקנה מפורטות — Node.js, npm ו-React ⚙️

## שלב 1: התקן Node.js

### Windows:
1. גש ל-[https://nodejs.org](https://nodejs.org)
2. לחץ על **"LTS"** (Long Term Support)
3. הורד את קובץ `.msi`
4. פתח את ה-installer ולחץ **Next → Next → Install**
5. אחרי ההתקנה — הפעל מחדש את VS Code

### בדיקה שההתקנה עבדה:
פתח **Terminal** ב-VS Code (`Ctrl + `` ` ``) וכתוב:
```bash
node --version
```
אמור להראות משהו כמו: `v20.11.0`

```bash
npm --version
```
אמור להראות משהו כמו: `10.2.4`

## שלב 2: צור פרויקט React חדש

### בחר תיקיה לפרויקט שלך:
```bash
cd Desktop
mkdir my-react-projects
cd my-react-projects
```

### צור פרויקט עם Vite (מהיר ומומלץ):
```bash
npm create vite@latest my-first-app -- --template react
```
כשישאל: פשוט לחץ Enter על ברירות המחדל.

### כנס לתיקיה והתקן ספריות:
```bash
cd my-first-app
npm install
```
(ייקח דקה-שתיים — מוריד ~200MB של ספריות ל-node_modules)

### הפעל את שרת הפיתוח:
```bash
npm run dev
```

### פתח בדפדפן:
גש ל-**http://localhost:5173**

## שלב 4: הפעל את הקוד מהשיעור

1. מחק את כל הקבצים בתיקיית `src/`
2. העתק לשם את הקבצים:
   - `App.jsx`
   - `Counter.jsx`
   - `UserCard.jsx`
   - `TodoApp.jsx`
3. צור קובץ `main.jsx` עם:

```jsx
import React from "react"
import ReactDOM from "react-dom/client"
import App from "./App"

ReactDOM.createRoot(document.getElementById("root")).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
)
```

## שלב 5: פקודות npm שימושיות

| פקודה | מה עושה |
|--------|----------|
| `npm run dev` | מפעיל שרת פיתוח (עם hot-reload) |
| `npm run build` | בונה גרסת production בתיקיית `dist/` |
| `npm install` | מתקין ספריות מ-package.json |
| `npm install axios` | מתקין ספרייה ספציפית |
| `npm install -D tailwindcss` | מתקין כ-devDependency |
| `Ctrl + C` | עוצר את השרת |

## 🚨 בעיות נפוצות

### "npm: command not found"
→ Node.js לא הותקן כראוי. נסה להתקין שוב.

### "EACCES: permission denied"
→ הרץ VS Code כמנהל מערכת (Run as Administrator)

### הדף לא מתרענן אוטומטית
→ בדוק שה-terminal רץ עם `npm run dev`

### שגיאה: "Cannot find module"
→ שכחת `npm install`! הרץ אותו בתיקיית הפרויקט.
